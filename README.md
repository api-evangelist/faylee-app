Faylee is a bug‑reporting tool for web applications, developed by Firefight Labs. It captures video, screenshots, console logs, network requests with headers and bodies, and the user’s steps, packaging everything into a single shareable link. Developers and AI coding agents can open the link to view the full context of a bug, facilitating faster debugging and fixing. Faylee offers a free tier for up to three members and thirty recordings per month, with paid plans for teams and enterprises. The service includes a Chrome‑based extension, a REST API, MCP server integration, and various free developer tools such as a HAR viewer, JWT decoder, and browser info utility.

**Areas:** bug reporting · developer tools · integrations · coding agents
